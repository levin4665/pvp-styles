# PvP Styles (Fabric, Minecraft 1.21.8, nur Client)

Menue per **Rechte Shift-Taste** (in den Steuerungs-Optionen aenderbar).

- 5 Styles (Ressourcenpakete), per Klick live an/aus
- FPS- und CPS-Anzeige
- "Weniger Partikel"
- Alles rein visuell/clientseitig

Eigene Texturen: PNGs in src/main/resources/resourcepacks/<style>/assets/minecraft/textures/... ablegen.
